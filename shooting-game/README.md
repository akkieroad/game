# NEON DRIFT / ネオンドリフト 🚀

HTML / CSS / JavaScript のみで作られた、ブラウザで**即起動できる**オリジナル縦スクロール・シューティング。
外部ライブラリ・画像・音声ファイルへの依存はゼロ（グラフィックは Canvas、効果音は Web Audio でプロシージャル生成）。

`index.html` をブラウザで開くだけで遊べます。

---

## ▶ 起動方法

### いちばん簡単（ダブルクリック）
`index.html` をダブルクリックしてブラウザで開くだけ。
本作は ES Modules や `fetch` を使わない**クラシックスクリプト構成**のため、`file://` 直開きでも動作します。

### ローカルサーバで開く（推奨・より確実）
一部ブラウザの厳格な設定でも確実に動かすには簡易サーバ経由が安心です。
```bash
cd shooting-game
python -m http.server 8000     # → http://localhost:8000 を開く
# もしくは:  npx serve .
```

### Web公開（静的ホスティング）
`shooting-game/` フォルダをそのまま GitHub Pages / Netlify / Cloudflare Pages にアップロードするだけ。ビルド不要。

## 📜 ルール

- 全**3ステージ**。各ステージは「敵編隊のウェーブ → ボス」で構成。ボスを倒すと次ステージへ。
- 3ステージすべてのボスを撃破すると **YOU WIN**。
- **残機**は初期3。各機は**シールド2**を持ち、2回まで被弾を吸収します。シールドが尽きた状態で被弾すると残機が1減り、残機0でゲームオーバー。
- 被弾直後は一定時間**無敵**で復帰します。**食らい判定は機体の見た目より小さい**ため、弾のかすりは当たりになりません。

### ドリフト・ブースト（本作の目玉）
`Shift`（または右クリック／BOOSTボタン）で短時間の高速移動。**発動中は無敵**になり、残像を引きながら弾幕を強引に抜けられます。ゲージ（画面下部のバー）が満タンのときのみ発動可能。使うとゲージを消費し、クールダウン後に自然回復します。

### ボム
画面の**敵弾を全消去**し、全敵に大ダメージを与える緊急回避。所持数は限られます（初期2）。

## 🏆 スコア仕様

| 要素 | 内容 |
|---|---|
| 基本点 | 敵種別ごとの得点（直進100 / 波動150 / 追尾250 / 砲台400） |
| **チェイン倍率** | 敵を連続撃破するほど倍率アップ（最大 **x8**）。約1.5秒撃破が途切れる、または被弾すると倍率リセット |
| **グレイズ（かすり）** | 敵弾を至近距離でかわすと加点＋ブーストゲージ回復。上級者ほど得をする |
| ステージクリアボーナス | ボス撃破時に加算 |
| ハイスコア | ブラウザの `localStorage` に上位5件を自動保存。タイトル／リザルトで表示 |

## 🌀 難易度調整

- タイトルで **EASY / NORMAL / HARD** を選択（敵の弾速・出現頻度の基準倍率）。
- 加えて **動的難易度調整（DDA）** を搭載。プレイヤーの被弾傾向を監視し、好調なら敵をやや強く、苦戦なら緩めに、上下限の範囲で自動調整します。

## 📁 ファイル構成

```
shooting-game/
├── index.html          エントリ。DOM骨格（Canvas / HUD / メニュー）と各scriptの読込
├── style.css           レイアウト・HUD・メニュー・レスポンシブ・テーマ変数
├── README.md           このファイル（操作・ルール・スコア・テスト手順）
└── js/
    ├── config.js       ゲーム定数・難易度プリセット・ステージデータ（ここで調整）
    ├── audio.js        Web Audio によるプロシージャルSE/BGM
    ├── input.js        キー/マウス/タッチ/パッドを共通コマンドへ正規化
    ├── game.js         ゲーム本体（ループ更新・エンティティ・当たり判定・スコア・DDA・描画）
    └── main.js         起動・固定タイムステップのループ・画面遷移・HUD/メニュー配線
```

### 設計のポイント
- **論理解像度固定（480×800）＋スケーリング**：どの画面でも比率を保って中央表示。`devicePixelRatio` で高精細化。
- **オブジェクトプール**で弾・敵・パーティクルを再利用し、GC負荷を抑制。
- **固定タイムステップ（60Hz）**：120Hz等の高リフレッシュ環境でも挙動が一定。
- **円判定**（平方根回避）による軽量な当たり判定。
- **ゼロアセット**：画像/音声ファイルが無いのでプリロード不要・オフラインでも即動作。

## 🧪 テスト手順

### 手動テスト（クロスブラウザ再現性）
以下のブラウザで「タイトル→1ステージ→リザルト」まで通しプレイし、描画・入力・音・スコア保存を確認します。
- デスクトップ：Chrome / Edge / Firefox / Safari
- モバイル：iOS Safari / Android Chrome（タッチUI・向き変更・オーディオ解錠）

チェック項目：
- [ ] タイトルで難易度を選び開始できる
- [ ] 移動・連射・ブースト・ボムが各入力手段で反応する
- [ ] スコア／チェイン倍率／残機／ボムのHUDが更新される
- [ ] ボス出現・撃破・ステージ遷移・YOU WIN／GAME OVER が表示される
- [ ] ハイスコアが再読み込み後も保持される（localStorage）
- [ ] ポーズ（P/Esc）と音量設定が機能する
- [ ] ウィンドウリサイズ・画面回転でレイアウトが崩れない

### デバッグモード
URL に `?debug=1` を付けて起動すると、**FPS・当たり判定円・グレイズ範囲・敵/弾数・DDA係数**が可視化されます。
`?debug=1&seed=12345` のように**シードを固定**すると敵出現を再現でき、バグの再現に便利です。
```
index.html?debug=1&seed=42
```

### 自動スモークテスト（開発時のみ・任意）
Playwright で主要フローを自動確認できます（配布物には含めません）。起動→難易度選択→数十秒プレイ→コンソールエラー0件・FPS・スコア更新を検証する簡易テストを想定しています。

- 難易度プリセット・DDAの効き
